The 'scroll-margin-block' property in CSS defines the margin that will be applied to the block-start and block-end of an element when it is scrolled into view. This is particularly useful for controlling the position of an element when navigating through a long page with anchors, ensuring that it doesn't get too close to the edges of the viewport. It enhances the user experience by providing better visual spacing around the element upon scroll.
