  :root { quotes: '"“" "”"'; } .quote { font-size: 24px; font-style: italic; }
  .quote::before { content: open-quote; } .quote::after { content: close-quote;
  }
---

The CSS 'quotes' property allows you to specify the type of quotation marks to be used for the content of the 'content' property when using the '::before' and '::after' pseudo-elements. This can enhance the visual presentation of quoted text in a web document. By defining custom quotes, you can ensure consistency and style across your web pages.
