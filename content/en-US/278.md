      scroll-behavior: smooth;
  }

  nav {
      position: fixed;
      top: 0;
      background: white;
      padding: 10px;
      width: 100%;
      box-shadow: 0 2px 5px rgba(0, 0, 0, 0.1);
  }

  .content {
      margin-top: 60px;
  }

  .section {
      height: 100vh;
      display: flex;
      align-items: center;
      justify-content: center;
      font-size: 2em;

  }

The 'scroll-behavior' CSS property allows you to control the scrolling behavior of a webpage when navigating to anchor links. By setting it to 'smooth', you can create a smooth scrolling effect instead of a sudden jump, enhancing the user experience when navigating long pages.
