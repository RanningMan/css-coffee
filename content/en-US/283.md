  .item {
    padding: 20px;
    border: 1px solid #000;
    margin: 10px 0;
  }

  #target {
    scroll-margin-inline: 20px;
    background-color: yellow;
    margin: 10px 0;
  }
---

The 'scroll-margin-inline' property in CSS defines the margin that will be applied to an element when it is scrolled into view. This margin is applied to the inline start and end of the element, allowing for better control over the positioning of the element when it is focused or targeted by scrolling actions. It helps create a more visually appealing layout by ensuring that elements do not stick too closely to the edges of their scroll container.
