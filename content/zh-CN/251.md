  hidden; }

  .scrollable { height: 400px; overflow-y: scroll; overscroll-behavior: contain;
  overscroll-behavior-block: contain; background-color: #f0f0f0; padding: 10px;
  }
---

'overscroll-behavior-block' CSS 属性控制在块方向（垂直）到达滚动容器边界时的滚动行为。通过设置此属性，可以防止滚动事件传播到父元素，从而通过保持焦点在特定内容区域内来提升用户体验。
