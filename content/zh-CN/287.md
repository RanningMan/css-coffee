  .scroll-container {
    height: 200px;
    overflow-y: scroll;
    scroll-padding-block: 50px;
    border: 2px solid #333;
  }
  .scroll-item {
    height: 100px;
    background-color: #f0f0f0;
    margin: 10px;
    display: flex;
    align-items: center;
    justify-content: center;
    border: 1px solid #ccc;
  }

    margin-top: 20px;
    padding: 10px 20px;
    font-size: 16px;
  }

CSS 中的 'scroll-padding-block' 属性定义了滚动容器在块开始和块结束的填充区域。它特别适用于控制当一个元素获得焦点或被导航到时的滚动位置，确保该元素出现在指定的填充区域内，从而提升可滚动区域的用户体验。
