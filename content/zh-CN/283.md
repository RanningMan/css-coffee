  .container {
    height: 200px;
    overflow-y: scroll;
    border: 1px solid #ccc;
  }

  .item {
    padding: 20px;
    border: 1px solid #000;
    margin: 10px 0;
  }

  #target {
    scroll-margin-inline: 20px;
    background-color: yellow;
    margin: 10px 0;
  }
---

CSS 中的 'scroll-margin-inline' 属性定义了当元素滚动到视图中时将应用于该元素的边距。这个边距应用于元素的行内起始和结束部分，使得在元素被聚焦或通过滚动操作定位时，可以更好地控制其位置。它有助于创建更具视觉吸引力的布局，确保元素不会过于紧贴其滚动容器的边缘。
