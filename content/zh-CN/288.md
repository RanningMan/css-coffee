  .scroll-container {
    height: 200px;
    overflow-y: scroll;
    border: 2px solid #333;
    scroll-padding-block-end: 30px;
  }

  .scroll-item {
    height: 100px;
    display: flex;
    align-items: center;
    justify-content: center;
    background-color: #f0f0f0;
    border: 1px solid #ccc;
    margin: 5px;
  }

  button {
    margin-top: 20px;
    padding: 10px;
    font-size: 16px;
  }
---

'scroll-padding-block-end' CSS 属性定义了滚动容器末端边缘的内边距区域，这会影响使用滚动相关方法时可滚动内容的对齐方式。这个属性特别有助于提升用户体验，确保在滚动到某个元素时，该元素不会被截断，尤其是在垂直布局中。
