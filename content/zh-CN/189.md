codeSnippet: |-
  .example-list {
    list-style-type: disc;
    list-style-position: inside;
    padding: 0;
    margin: 0;
  }

  .example-list li {
    background-color: lightblue;
    margin: 5px;
    padding: 10px;
    border: 1px solid blue;
    list-style-position: inside;
  }
---

CSS 中的 'list-style-position' 属性用于指定列表项标记（项目符号或数字）相对于列表项内容的位置。它可以取两个值：'inside'，表示标记放置在列表项内容流内；'outside'，表示标记放置在内容流外。这个属性对于控制网页中列表的布局非常有用。
