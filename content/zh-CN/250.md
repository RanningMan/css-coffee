  .container { height: 200px; width: 300px; overflow: auto; border: 2px solid
  #333; overscroll-behavior: contain; } .inner { height: 600px; width: 100%;
  background: linear-gradient(to bottom, #ffcc00, #ff6699); }
---

'overscroll-behavior' CSS 属性控制容器在达到可滚动区域边界时的行为。它可以防止默认的滚动链式行为，从而更好地控制嵌套可滚动元素中的滚动。这在提升移动应用的用户体验方面特别有用。
