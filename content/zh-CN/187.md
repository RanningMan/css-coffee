  .custom-list {
    list-style: square;
    padding-left: 20px;
    color: #333;
  }

  .custom-list li {
    margin-bottom: 10px;
    font-size: 18px;
  }
---

CSS 中的 'list-style' 属性用于指定无序列表或有序列表中列表项的外观。它允许您控制每个列表项前面出现的标记类型（例如项目符号或数字），以及其位置和样式。通过使用此属性，您可以创建视觉上吸引人的列表，从而增强网页的整体设计。
