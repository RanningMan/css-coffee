    width: 300px;
    overflow-x: auto;
    border: 2px solid #333;
    scroll-padding-inline: 20px;

    display: flex;
  }

  .item {
    min-width: 100px;
    height: 100px;
    margin-right: 10px;

CSS 中的 'scroll-padding-inline' 属性定义了在滚动到某个元素时，内联轴（左右方向）的填充区域。这个属性在创建舒适的视觉体验时特别有用，因为它确保目标元素在滚动到视口时不会紧贴视口的边缘，尤其是在横向滚动的场景中。
