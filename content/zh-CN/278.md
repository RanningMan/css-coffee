  html {
      scroll-behavior: smooth;
  }

  nav {
      position: fixed;
      top: 0;
      background: white;
      padding: 10px;
      width: 100%;
      box-shadow: 0 2px 5px rgba(0, 0, 0, 0.1);
  }

  .content {
      margin-top: 60px;
  }

  .section {
      height: 100vh;
      display: flex;
      align-items: center;
      justify-content: center;
      font-size: 2em;

      border: 1px solid #ccc;
  }

'scroll-behavior' CSS 属性允许您控制网页在导航到锚链接时的滚动行为。将其设置为 'smooth'，您可以创建平滑的滚动效果，而不是突然跳转，这样可以提升用户在浏览长页面时的体验。
