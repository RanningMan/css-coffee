    display: grid;
    grid-template-columns: repeat(2, 1fr);
    row-gap: 20px;
  }

  .grid-item {
    background-color: #4CAF50;
    color: white;
    padding: 20px;
    text-align: center;
    border: 2px solid #fff;
    margin: 5px;
  }

CSS中的'row-gap'属性用于定义网格或弹性容器中行与行之间的垂直间距。它可以更好地控制元素的布局，确保元素之间有足够的空间，而不影响它们各自的外边距。
