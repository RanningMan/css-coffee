  .text-container {
      width: 200px;
      border: 1px solid #ccc;
      padding: 10px;
  }

  .text-container p {
      line-break: strict;
      word-wrap: break-word;
  }
---

'line-break' CSS 属性控制文本块中如何换行。它对于管理具有不同换行规则的语言（如日语或中文）特别有用。这个属性可以通过更好地控制换行位置来提高可读性和布局效果。
