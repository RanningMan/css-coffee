    width: 100%;
    border: 2px solid #007BFF;
    padding: 20px;
    box-sizing: border-box;
  }

  .content {
    max-inline-size: 300px;
    background-color: #f0f8ff;
    padding: 10px;
    border: 1px solid #007BFF;
    margin: auto;
    text-align: center;
    overflow: hidden;
    white-space: nowrap;
    text-overflow: ellipsis;
  }

'max-inline-size' CSS 属性设置元素在行内方向上的最大尺寸，通常在从左到右的书写模式中是水平的。这个属性对于控制元素的宽度非常有用，允许更好地管理布局，而无需明确设置宽度。它通过限制文本块或其他行内元素的大小，帮助保持设计的响应性。
