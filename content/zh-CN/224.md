codeSnippet: |-
  .container {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
    background-color: #f0f0f0;
  }

  .box {
    background-color: #4CAF50;
    color: white;
    padding: 20px;
    min-inline-size: 200px; /* Sets a minimum width */
    border-radius: 5px;
    text-align: center;
    transition: width 0.3s;
    width: 150px; /* Initial width less than min-inline-size */
  }

  .box:hover {
    width: 300px; /* Expands to a width greater than min-inline-size on hover */
  }
---

'min-inline-size' CSS 属性设置元素在行内方向上的最小尺寸，这个尺寸由书写模式决定。这个属性对于确保元素不会缩小到指定宽度以下非常有用，从而在响应式设计中更好地控制布局和可读性。
