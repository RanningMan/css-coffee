  .container {
      width: 300px;
      height: 150px;
      overflow: auto;
      border: 2px solid #333;
      padding: 10px;
      position: relative;
  }

  .content {
      overflow-anchor: auto;
  }

  .load-more {
      margin-top: 10px;
      padding: 5px 10px;
      background-color: #007BFF;
      color: white;
      border: none;
      cursor: pointer;
  }

  .load-more:hover {
      background-color: #0056b3;
  }
---

CSS 中的 'overflow-anchor' 属性用于控制元素在内容溢出其框时的行为。将 'overflow-anchor' 设置为 'auto' 时，浏览器会尽量保持滚动位置，当新增内容时，可以防止布局的突然跳动。这在动态加载内容的场景中尤其有助于提升用户体验。
