codeSnippet: >-
  :root { quotes: '"“" "”"'; } .quote { font-size: 24px; font-style: italic; }
  .quote::before { content: open-quote; } .quote::after { content: close-quote;
  }
---

CSS 的 'quotes' 属性允许您指定在使用 '::before' 和 '::after' 伪元素时，'content' 属性内容所使用的引号类型。这可以增强网页文档中引用文本的视觉效果。通过定义自定义引号，您可以确保网页的一致性和风格。
