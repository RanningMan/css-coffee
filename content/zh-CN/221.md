  .container {
    max-width: 600px;
    margin: 0 auto;
    padding: 20px;
    background-color: #f0f0f0;
    border: 1px solid #ccc;
    box-shadow: 2px 2px 10px rgba(0, 0, 0, 0.1);
  }

  h1 {
    color: #333;
  }

  p {
    color: #666;
  }

CSS 中的 'max-width' 属性设置元素的最大宽度，防止其超过指定的值。这在响应式设计中非常有用，允许元素在灵活布局中调整大小，同时保持宽度的限制。它有助于确保内容在不同屏幕尺寸上保持可读性和视觉吸引力。
