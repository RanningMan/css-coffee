  .overlay { position: absolute; top: 0; left: 0; width: 100%; height: 100%;
  background-color: rgba(255, 0, 0, 0.5); pointer-events: auto; }

  .clickable { position: relative; z-index: 1; padding: 10px 20px;
  background-color: #4CAF50; color: white; border: none; cursor: pointer; }

'pointer-events' CSS 属性决定了一个元素如何响应鼠标事件。将其设置为 'none' 时，该元素对鼠标交互变得透明，允许点击事件穿透到其后面的元素。这在创建覆盖层或管理 z-index 堆叠时非常有用，而不会干扰用户交互。
