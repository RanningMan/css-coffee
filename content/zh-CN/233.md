  .container { position: relative; width: 300px; height: 300px; border: 2px
  solid #000; } .box { position: absolute; width: 100px; height: 100px;
  background-color: coral; offset-position: 50px 50px; transform:
  translate(50px, 50px); }
---

CSS 中的 'offset-position' 属性定义了元素的偏移容器的位置。它决定了元素相对于其偏移父元素的位置，从而可以精确控制元素在布局中的放置。这个属性与 'position' 属性结合使用时尤其有用，可以创建复杂的布局和动画。
