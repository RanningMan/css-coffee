codeSnippet: |-
  .shape {
    width: 200px;
    height: 200px;
    background-color: #4CAF50;
    clip-path: circle(50% at 50% 50%);
    shape-margin: 20px;
    margin: 50px;
    display: inline-block;
    position: relative;
  } 

  body {
    background-color: #f0f0f0;
    padding: 20px;
  }
---

CSS 中的 'shape-margin' 属性定义了形状周围的空间，提供了一个边距区域，可以用来将形状与周围内容分开。这个属性在使用 'clip-path' 属性定义形状时特别有用，能够更好地控制涉及非矩形元素的设计布局和间距。
