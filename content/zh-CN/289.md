  .container {
    height: 200vh; /* Make the container tall enough to scroll */
    padding: 20px;
    scroll-padding-block-start: 100px; /* Set padding for scroll position */
  }

  h1 {
    margin-top: 100px; /* Space between sections */
  }

  nav {
    position: fixed;
    top: 10px;
    background: rgba(255, 255, 255, 0.8);
    padding: 10px;
    border-radius: 5px;
    box-shadow: 0 2px 5px rgba(0, 0, 0, 0.2);
  }

  p {
    margin: 20px 0;
  }

'scroll-padding-block-start' CSS 属性定义了滚动容器块开始侧的内边距区域。这个内边距区域用于在导航到容器内的锚链接时调整滚动位置，确保目标元素不会被固定头部或其他元素遮挡。它通过提供更具视觉吸引力的滚动效果来提升用户体验。
