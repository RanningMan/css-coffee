  } @keyframes move { 0% { offset-distance: 0%; } 100% { offset-distance: 100%;
  } }

CSS 中的 'offset-distance' 属性与 'offset-path' 属性一起使用，用于控制元素沿定义路径的距离。这使得元素沿指定路线平滑移动和定位，适合用于创建动态布局和效果。
