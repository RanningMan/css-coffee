codeSnippet: |-
  .container {
    width: 100%;
    background-color: #f0f0f0;
    padding: 20px;
  }

  .box {
    min-width: 200px;
    width: 100%;
    background-color: #4CAF50;
    color: white;
    padding: 20px;
    text-align: center;
    border: 2px solid #388E3C;
    transition: width 0.3s;
  }

  .box:hover {
    width: 300px;
  }
---

'min-width' CSS 属性设置元素的最小宽度。这意味着该元素的宽度不能小于指定的值，无论内部内容是什么。它对于确保元素保持一定的大小以便更好地控制布局非常有用，特别是在响应式设计中。
