codeSnippet: >-
  .scroll-container { display: flex; overflow-x: auto;
  scroll-padding-inline-end: 50px; border: 2px solid #333; }

  .scroll-container::-webkit-scrollbar { height: 8px; }

  .scroll-container::-webkit-scrollbar-thumb { background: #888; border-radius:
  10px; }

  .scroll-container::-webkit-scrollbar-thumb:hover { background: #555; }

  .item { min-width: 100px; padding: 20px; margin: 10px; background-color:
  #4CAF50; color: white; border-radius: 5px; }
---

'scroll-padding-inline-end' 是一个 CSS 属性，用于设置滚动容器的内边距，特别是在滚动时控制内容的位置。这个属性在你希望确保可滚动区域中的最后一个元素不会紧贴边缘时特别有用，从而提高可见性和美观性。
