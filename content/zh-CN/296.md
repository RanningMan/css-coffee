codeSnippet: >-
  .image-container { width: 300px; height: 200px; overflow: hidden; position:
  relative; }

  .shaped-image { width: 100%; height: auto; clip-path: polygon(10% 0%, 100%
  10%, 90% 100%, 0% 90%); shape-image-threshold: 0.5; }
---

'shape-image-threshold' CSS 属性定义了在与 'clip-path' 属性一起使用时，图像 alpha 通道的阈值。它通过指定图像 alpha 通道的多少部分被视为不透明，从而允许创建非矩形形状。这使得设计师能够创建视觉上更具吸引力的布局，使图像更自然地融入他们的设计中。
